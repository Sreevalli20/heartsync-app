💡 About HeartSync

In today's digitally connected world, staying in touch has never been easier. Yet, meaningful connection often gets lost between busy schedules, physical distance, and conversations that never go beyond “How are you?”

HeartSync bridges the gap between being connected and feeling connected.

It is a relationship-focused application designed to help people nurture meaningful relationships through intentional check-ins, emotional awareness, thoughtful conversations, personal memories, and timely reminders.

Rather than replacing existing messaging applications, HeartSync complements them by making it easier to recognize, prioritize, and act on the moments that matter.

🎯 The Problem

People can exchange messages every day and still feel emotionally disconnected.

Three major challenges contribute to this gap:

Time and distance: Busy schedules, academic commitments, work, and relocation make consistent communication difficult.
Emotional awareness: It is difficult to understand how someone genuinely feels through ordinary text conversations.
Consistency: Birthdays, important milestones, meaningful conversations, and small opportunities to reconnect are easily overlooked.

The problem is not a lack of communication platforms. It is the lack of tools designed to encourage consistent, intentional, and emotionally meaningful connection.

✨ Our Solution

HeartSync turns relationship maintenance into a simple, intentional daily experience.

It encourages users to check in with themselves, reflect on their feelings, initiate thoughtful conversations, preserve meaningful memories, and remember important moments.

The goal is simple: less superficial interaction, more meaningful connection.

🚀 Key Features
💜 1. Daily Mood Check-ins
Record a mood through a simple, low-friction interaction.
Add optional personal reflections.
Review previous check-ins and recognize personal patterns.
Keep emotional information private unless explicitly shared through a supported feature.
💬 2. Meaningful Conversation Prompts
Explore thoughtful conversation starters.
Discover prompts focused on gratitude, friendship, family, memories, and emotional well-being.
Save favorite prompts and revisit meaningful questions.
Encourage conversations that go beyond routine greetings.
📸 3. Personal Memories Timeline
Preserve meaningful moments through notes, dates, and supported images.
Organize memories using tags and milestones.
Search, revisit, and manage saved memories.
Keep meaningful experiences accessible instead of losing them in long conversation histories.
🔔 4. Smart Personal Reminders
Organize birthdays, anniversaries, milestones, and planned check-ins.
Create customized reminders.
Manage upcoming and completed reminders.
Make it easier to act on opportunities to reconnect.
📝 5. Private Reflection Space
Record personal thoughts and feelings.
Identify the type of support needed, such as listening, encouragement, advice, or practical help.
Maintain a dedicated space for emotional reflection.
🫶 6. “I Need You” Support Flow
Help users express when they need emotional support.
Prepare a message for a trusted person.
Use supported sharing options where available.
Communicate clearly whether a message has actually been sent or delivered.
🔐 7. Privacy and Personal Control
Provide clear privacy preferences.
Make the visibility of personal information understandable.
Avoid exposing sensitive emotional information without consent.
Give users control over their personal data.
👤 8. Personal Profile
Allow users to manage their own profile information.
Support personal preferences and settings.
Avoid fabricated identities and misleading account information.
🔄 How HeartSync Works

HeartSync follows an intentional connection cycle:

Reflect: Understand your current mood and emotional needs.
Reconnect: Choose a meaningful prompt or plan a check-in.
Remember: Preserve important experiences and milestones.
Follow through: Use reminders to turn good intentions into meaningful actions.

This cycle makes relationship maintenance more deliberate without adding unnecessary complexity to everyday life.

🛠️ Technology

The application is developed using the tools and technologies supported by its implementation environment.

The frontend architecture uses:

React: Component-based user interface.
TypeScript: Type-safe application development.
Responsive web design: Support for mobile and desktop screens.
Browser storage: Local persistence for all personal features.
Curated content: Pre-built prompts and responses for a complete experience without external dependencies.

The application runs entirely in the browser with no backend server required.

🔒 Privacy and Data Integrity

HeartSync is designed around trust and transparency.

Personal information should be provided by the actual user.
Personal reflections and mood entries should not be represented as shared information without explicit consent.
Local data should be identified as local rather than cloud-synchronized.
Cross-user features should not claim successful delivery or synchronization without a functioning delivery mechanism.
Access to private information must be appropriately restricted when shared services are enabled.
💻 Getting Started
Prerequisites
A modern web browser.
Access to the generated HeartSync project.
Node.js and npm if the generated project uses a standard React development environment.
Installation

Clone the repository:

git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <YOUR_PROJECT_DIRECTORY>


Install dependencies:

npm install


Start the development server:

npm run dev


Open the local URL displayed in the terminal (usually http://localhost:3000).

The application works entirely with curated content and smart fallback responses—no API keys or external services required.

Development Commands:
- npm run dev - Start the Vite development server (port 3000)
- npm run build - Build for production
- npm run preview - Preview production build

🚀 Deployment

HeartSync is a static React application that can be deployed to any hosting platform that supports static sites. No backend server, database, or API keys are required.

Option 1: Vercel (Recommended)
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

Option 2: Netlify
```bash
# Install Netlify CLI
npm i -g netlify-cli

# Build the project
npm run build

# Deploy
netlify deploy --prod --dir=dist
```

Option 3: GitHub Pages
```bash
# Build the project
npm run build

# Deploy using gh-pages
npm install -D gh-pages
npx gh-pages -d dist
```

All deployment options work with the curated content system—no configuration or API keys needed.
